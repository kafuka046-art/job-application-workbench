# 用虚构资料体验求职工作台

本 Demo 的姓名、组织、岗位和数字均为虚构，不是实际招聘信息或真实经历。

## 网页操作

1. 打开仓库根目录的 `index.html`。若已有个人资料，先“导出备份”。
2. 点击“导入数据”，选择 `examples/demo-data.json`。
3. 经历库应显示“林同学”和两段带“虚构案例”标记的经历。
4. 进入“JD匹配”，点击“生成选材建议”，查看关键词与粗匹配结果。
5. 勾选相关经历，进入“分析包”，检查复制文本是否含 JD、经历和真实性边界。
6. 把分析包与 Skill 交给外部 AI，要求先分析和选材；确认后再生成材料。
7. 回到“投递记录”登记当前岗位；演示时保留“待投递”，不模拟真实提交成功。
8. 导出 JSON，再导入检查资料和状态是否保留。

## 应看到的边界

- 网页可在本地打开，不需要模型 API Key。
- 网页不会发送 AI 请求；它生成的是供外部 AI 使用的文本。
- 匹配分数是关键词粗匹配；虚构公司的开放状态无需也不能当成真实岗位验证。
- 完整查岗位与制作材料流程见 `skill/campus-application-workflow/references/demo.md`。
